# Admin Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan in the current session.

**Goal:** Let authorized club editors maintain existing content without editing code.
**Architecture:** Supabase REST-backed documents with server authentication and revision-safe draft/publish operations; public rendering reads only published values and retains repository defaults before setup.
**Tech Stack:** Existing Next.js 16 / React 19 / TypeScript, Supabase Free; existing sharp 0.35.5 declared directly for image sanitation.
**Spec:** `docs/superpowers/specs/2026-10-11-admin-design.md`

## Global Constraints

- No paid service, no public registration, no secrets in browser bundles or Git.
- Preserve current night design, EN default and ES alternative, reviewed defaults, existing routes and separation of events/culture/Niagara/countries.
- Commit/push checked milestones to `work`; keep `main` unchanged.
- Upload JPEG/PNG/WebP up to 3 MiB. Admin publishes; Editor saves drafts.

## Review Focus

- Missing configuration must never pretend a change was saved.
- Forged/expired sessions, unassigned accounts and cross-origin writes must fail.
- Public visitors must never receive draft text or unreferenced private uploads.
- Concurrent editors must get a conflict instead of overwriting newer work.
- Invalid bilingual fields, URLs, dates and geographical coordinates must fail before publication.
